# Feeds de Torremolinos PLUS

Copia de los feeds RSS de las campañas «Save the date» de torremolinosplus.com, servida con GitHub Pages en `https://feeds.torremolinosplus.com/std/<campaña>/<es|en>.xml`.

Los genera y los sube el plugin `tp-core` del sitio (`inc/std-feed-espejo.php`): no se editan a mano. Existen porque la protección contra bots de SiteGround bloquea a ratos al lector RSS de MailerLite.
